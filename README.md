GeoFS MXWL Military is an addon that adds basic (for now) military features to the game. Including Missiles, Guns, and Radars. 

This Addon has nothing to do with GMRP or any GeoFS military roleplay community. I'm saying this because recently, Google's AI kept stating that this addon is made to enhance your MRP experience.

**Current script version 0.0.2**

**Keep in mine that for now, it only works with GeoFS 4.0**

Paste the code in tampermonekey.

**CONTROLS**

**L** = WEAPON SYSTEM ON / OFF

**SHIFT** = FIRE MISSILES

**ENTER** = FIRE GUNS


Spawn in one if these planes (Su-35, F/A-18, rafale, F-16)

Make sure to turn your engines off before selecting missiles.

*more stuff will be added in the future*
